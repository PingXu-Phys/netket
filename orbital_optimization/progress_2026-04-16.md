## 当前仍需注意的点

### 1. 这还是第一版工程落地，不是最终版

当前代码重点是把流程跑通，而不是追求最精致的几何优化实现。

尤其是：

- pruning 里的修复仍是轻量投影 + polar
- sparse 里的 refinement 目前优先支持近似 real rotation

### 2. `optimize_no.py` 还没有完全退场

虽然主干已经开始转向 `orbital_*`，但 `optimize_no.py` 还没有完全压成纯 compatibility layer。

### 3. `orbital_optimizer.py` / `orbital_losses.py` 还是薄入口

它们当前是对 `optimize_no_core.py` / `optimize_no_losses.py` 的重导出。

这没有问题，但后续如果继续收敛工程结构，应该逐步把真正实现也迁到 `orbital_*` 名下，而不是长期停留在 alias 形态。

### 4. `pytest` 还没直接跑

当前指定 Python 环境里没有 `pytest`，所以目前的验证方式是：

- `py_compile`
- 直接用 Python 运行 smoke case

这足够验证主线逻辑，但还不等于 repo 级完整测试流程已经接通。
